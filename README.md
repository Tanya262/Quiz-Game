**Features:**

It has multiple choice questions.

It has score tracker and question tracker

It shows correct and incorrect answers

It has progress bar which grows with new questions.

It shows final score at the end

confetti effect. if you get perfect score, you get a celebration!!

Result messages according to your score.

Start and re-start quiz function.

It has responsive design. It is responsive till 500px. (max-width)




**What I learnt:**

DOM elements

link JavaScript file

handling click events (it took me 2 days to make the quiz work because I didn't add click element)

how to manage quiz question numbers and scores

CSS styling (media query, overflow, cursor, hover (how styling can change when arrow hover), transition)

adding confetti link from external javacript library
